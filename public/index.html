ℹ️ How this works

On each scheduled tick (and when you press Run now) the bot creates one Activity (POST /api/activities) and joins members to it (POST /api/activity-members) — it does not create events:

  • A random host from your pool, plus a random number of members.
  • A random real location inside Israel with slight jitter.
  • Your chosen duration and activity type, optionally a random dojo.
  • With auto-end on, it ends the activity once the duration elapses.

Every Strapi call is shown in the API log at the bottom.

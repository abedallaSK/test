ℹ️ How this works

On each Activities tick (and when you press Run now) the bot creates one Activity (POST /api/activities) and joins members to it (POST /api/activity-members):

  • A random host from your pool, plus a random number of members.
  • A random real location inside Israel with slight jitter.
  • Your chosen duration and activity type, optionally a random dojo.
  • With auto-end on, it ends the activity once the duration elapses.

Everything runs against the selected environment. Events have their own schedule on the Events tab.

ℹ️ How this works

Manage release notes and "What's New" entries for your app versions. Each entry includes:

  • Version number (e.g., 1.2.3) — required identifier.
  • Title & Description — what's new in this version.
  • Platform — target iOS, Android, or all platforms.
  • Image — optional screenshot or icon.
  • Order — controls display order (higher = first).
  • Active — toggle visibility.

Changes are applied to the selected environment. Use the "Apply to All Envs" button to sync across all environments.
